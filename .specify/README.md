# .specify — spec-kit scaffolding (minimal)

This is the **minimal** spec-kit setup for soulrealm, enough to author feature
specs in the house format with the constitution wired in:

- [`memory/constitution.md`](memory/constitution.md) — a **symlink** to
  `hq/00-GENESIS/constitution.md`, so every plan's Constitution Check reads the
  canonical articles (the pattern `hq/00-GENESIS/how-we-work.md` commits to).
- [`templates/`](templates/) — the generic spec / plan / tasks / checklist
  templates.

Feature specs live in `specs/NNN-<slug>/` at the repo root. What is
*deliberately not here yet*: the spec-kit CLI glue (branch scripts, workflow
registry, integration manifests). Those are generated by the spec-kit tool, not
hand-authored; run the spec-kit init if/when the fully-automated flow is wanted.
Until then, specs are authored against `templates/spec-template.md` following
`hq/00-GENESIS/how-we-work.md`.
